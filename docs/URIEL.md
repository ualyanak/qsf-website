# Uriel research access

Uriel is hosted separately at https://qsf-uriel-research.pirlon.chatgpt.site.
The public investor login links to this private research workspace. Entering
`uriel` in the public login sends the visitor there without reading or checking
a password in this repository.

The research site's source repository and server-side access secrets are separate
from this intentionally public investor demonstration. Private Site authorization
requires the owner's authorized ChatGPT sign-in, followed by Uriel's workspace
password. A weak workspace password is not the only access control.

The research portal does not place trades, connect a broker, or maintain balances.
Its guide distinguishes observed market data, frozen predictive fits, experimental
physics simulations, fundamental valuation assumptions, and model option prices.

This addition does not change the visibility of ualyanak/qsf-website, or secure
the existing intentionally public ahub/chue demonstration. Browser-delivered
HTML, CSS and JavaScript remain inspectable by a visitor who can access a page.

The pre-change investor login is preserved in
`private/rollback/2026-09-06-uriel/investor_login/index_OLD.html`.
